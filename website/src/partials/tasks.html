AI Agents Running Your Operations

Specialized agents pick up tasks, execute them, and report back. Like handing your company's ops to a team of AI workers.

tasks.ts 
// Create a task
await claw.tasks.create({
  title: "Draft Q2 report",
  agent: "analyst",
});

// List by status
const open = await claw
  .tasks.list({
    status: "in_progress"
  });

// Assign to agent
await claw.tasks.assign(
  "task_id", "ops-agent"
);
