Workflow Builder, Powered by Agents

AI agents propose, connect, and monitor automation flows. Drag-and-drop nodes, animated execution previews, and approval-gated runs keep humans in control of external actions.

workflows.ts 
// Create a workflow
const flow = await claw
  .workflows.create({
    name: "Lead Nurture",
    trigger: "webhook"
  });

// Add nodes
await claw.workflows
  .addNode(flow.id, {
    type: "condition",
    rule: "score > 80"
  });

// Run the flow
const run = await claw
  .workflows.run(
    flow.id
  );
