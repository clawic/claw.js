Your Entire Network, Agent-Managed

AI agents enrich profiles, schedule follow-ups, track deals, and keep every relationship warm. Personal and professional, all in one place.

contacts.ts 
// Add a contact
await claw.contacts.create({
  name: "Sarah Chen",
  email: "sarah@co.io",
  tags: ["lead"]
});

// Enrich profile
await claw.contacts
  .enrich("sarah@co.io");

// Schedule follow-up
await claw.contacts
  .followUp("sarah@co.io",
    { in: "3 days" }
  );
