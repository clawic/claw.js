Images

Generate and Edit Images with One Command

A full image dashboard, built in. Type a prompt, watch the model paint. Edit, re-roll, and tag, all from the CLI or a single function call.

Terminal
images.ts 
// Generate a new image
const img = await claw
  .images.create({
    prompt: "logo for Claw, pink orbit",
    type: "logo"
  });

// Edit an existing one
await claw.images.edit(img.id, {
  prompt: "make it warmer, add glow"
});

// List & filter
const logos = await claw
  .images.list({ type: "logo" });
