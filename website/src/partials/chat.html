Chat Preview

Built-in Conversational UI

A full streaming chat interface out of the box. Markdown, voice notes, context chips, and multi-session support.

chat.ts 
// List conversations
const sessions = await claw
  .chat.sessions();

// Send a message
await claw.chat.send("Hello!");

// Stream response
for await (const chunk of
  claw.chat.stream()) {
  render(chunk);
}

// Mount full UI
claw.chat.mount("#app");
