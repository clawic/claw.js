Help Desk

AI-Powered Support, Zero Wait Time

Agents triage tickets, draft replies, escalate critical issues, and resolve conversations. A full Zendesk-class inbox where every seat is an autonomous agent.

helpdesk.ts 
// Open tickets
const tickets = await claw
  .helpdesk.list({
    status: "open"
  });

// Auto-triage
await claw.helpdesk
  .triage("T-1042");

// Draft a reply
const reply = await claw
  .helpdesk.draft(
    "T-1042"
  );

// Resolve
await claw.helpdesk
  .resolve("T-1042");
