# Service Surfaces
<!-- migrated-to: catalog:agent-rules.service-surfaces.surfaces.write -->

Use the product surface that owns the domain:

- Relay: remote clients, connectors, shared browser sessions, tenant/project/agent/workspace routing.
- Media/image/audio/video: generated or imported assets, metadata, sharing.
- Time: events, routines, reminders, deadlines, follow-ups, executions, calendars, timelines.
- Notify: alerts, glances, receipts, subscriptions, device feeds.
- Content: brands, campaigns, entries, variants, approvals, publishing.
- IoT: homes, areas, things, state, actions, scenes, automations, approvals.
- Database: namespace collections, tokens, records, files, realtime.
- ERP: tenant/company, ledger-backed business operations, approvals, reports.
- Drive: folders, docs, sheets, slides, uploads, previews, revisions, share links.
- Execution plane: runs, artifacts, workers, reviews, deployments.
- Delegation plane: durable child-agent graphs, leases, retries, continuations.
