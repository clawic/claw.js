# Nodes, Cluster, And Local Forge Source Audit

Source conversation: `source:nodes-cluster-local-forge`

Plan reference: `plan:nodes-cluster-local-forge`

This audit converts conversation-made architecture decisions into public-safe
rows. It intentionally stores no transcript text, private paths, credentials,
or local goal identifiers.

| ID | Decision key | Architecture impact | State | Evidence refs | Remaining work |
| --- | --- | --- | --- | --- | --- |
| NCLF-001 | `node_vocabulary` | Public machine vocabulary uses `node`; `cluster` stays internal/advanced. | documented | ADR 0053, decision matrix. | Implement visible UI/CLI copy through surfaces checklist. |
| NCLF-002 | `cluster_boundary` | V1 active cluster boundary is the framework root, normally `~/.claw`. | documented | ADR 0053. | Do not add broad `clusterId` columns without superseding ADR. |
| NCLF-003 | `single_cluster_root` | One hardware identity must not mix active clusters through one root in V1. | documented | ADR 0053. | Multi-cluster-in-one-root remains blocked. |
| NCLF-004 | `single_computer_hidden_complexity` | Single-computer users should not see node/cluster complexity. | documented | ADR 0053. | Validate in future Clawix flows. |
| NCLF-005 | `reuse_existing_surfaces` | Control-plane work composes existing nodes, remote, sync, gateway, resources, host, system, agents, database, search, approvals, grants, and diagnostics surfaces. | documented | ADR 0053, ADR 0022. | Add new routes only as views or extensions. |
| NCLF-006 | `logical_database_service` | Callers use logical framework service contracts, not direct reads of another node database file. | documented | ADR 0053, data-storage boundary. | Implementation tests needed for any cross-node DB access. |
| NCLF-007 | `policy_driven_replication` | No durable user data class replicates blindly by default. | implemented | ADR 0053, Sync manifest model, `clusterStoragePolicyReceiptSchema`, focused remote contract tests. | Physical driver execution remains `EXTERNAL PENDING`. |
| NCLF-008 | `secret_refs_only` | Secrets cross node/sync boundaries only as refs, envelopes, or brokered operations; plaintext never replicates. | documented | ADR 0053, ADR 0022, secrets docs. | Physical provider evidence remains blocked. |
| NCLF-009 | `conservative_failover` | V1 failover starts with primary coordinator, standby/export-restore, snapshots, and auditable promotion. | implemented | ADR 0053, `clusterCoordinatorRecordSchema`, `clusterExportRestoreReceiptSchema`, focused remote contract tests. | Physical multi-node promotion remains `EXTERNAL PENDING`. |
| NCLF-010 | `last_known_good_policy` | Authorized local work may continue from local policy snapshots; new authority decisions fail closed when coordinator is unavailable. | implemented | ADR 0053, `clusterPolicySnapshotSchema`, `evaluateClusterAuthority`, focused remote contract tests. | Signed-host persistence remains separate. |
| NCLF-011 | `resource_location_views` | `claw get`, `claw describe`, `claw where`, and `claw risk` are transversal views over existing surfaces. | implemented | ADR 0053, CLI registry, `cli-remote-sync-command.ts`, focused CLI tests. | Generic non-worktree resource describe remains blocked with checklist reentry. |
| NCLF-012 | `worktree_resource_class` | Large editable folders are worktree resources, not blind sync folders. | implemented | ADR 0053, ADR 0054, `LocalForgeWorktreeRecord`, `claw project worktree`, `claw get worktrees`. | Physical multi-node checkout remains `EXTERNAL PENDING`. |
| NCLF-013 | `session_index_conservative` | Full session stores remain node-local by default; no broad cluster session index in V1 without a specific design. | documented | ADR 0053. | Future session indexing requires separate proof. |
| NCLF-014 | `metrics_logs_summary` | Raw metrics/logs stay node-local by default; cluster-visible state is current health, summaries, incidents, and rollups. | implemented | ADR 0053, `operationalSummary` on node inventory views, focused CLI tests. | Retention/indexing and physical monitor rollups remain blocked until a bounded monitor adapter is implemented. |
| NCLF-015 | `desired_observed_state` | Desired/observed cluster state uses typed resources and projections, not required user-edited YAML. | implemented | ADR 0053, cluster coordinator/policy/storage receipts, focused remote contract tests. | Physical controller reconciliation remains `EXTERNAL PENDING`. |
| NCLF-016 | `existing_folder_no_mutation` | Registering an existing folder as a project must not mutate it by default. | implemented | ADR 0054, ADR 0028, `project attach` preview tests. | Clawix UI attach proof remains blocked. |
| NCLF-017 | `existing_git_detected` | Existing Git repos are detected and used without changing user expectations. | implemented | ADR 0054, `project attach` existing-Git preview test. | Full forge review/recovery over Git remains blocked. |
| NCLF-018 | `non_git_history_opt_in` | Non-Git version history is opt-in per folder/project or workspace policy. | implemented | ADR 0054, `ClawProjectAttachPreview.versionHistory`. | Version-history enablement backend remains blocked. |
| NCLF-019 | `human_copy_version_history` | Human copy says version history/save versions/review/recover, not required Git concepts. | documented | ADR 0054. | UI copy checks remain blocked. |
| NCLF-020 | `git_preferred_substrate` | Git or Git-compatible storage is preferred when version history is enabled. | documented | ADR 0054. | V1 large files use `block_by_default`; future LFS/blob/provider storage requires a later enablement decision. |
| NCLF-021 | `agent_layer_above_git` | Claw adds deterministic branches, hashes, snapshots, checkpoint commits, review records, merge plans, and recovery receipts. | blocked | ADR 0054, `LocalForgeSnapshotRecord`, `LocalForgeReviewRecord`, `LocalForgeMergePlanRecord`, `LocalForgeRecoveryReceipt`, focused CLI tests. | Metadata-only snapshots/reviews/merge-plans/recovery exist. Blocker: actual Git checkpoint commits are not implemented. Reentry: add opt-in Git checkpoint policy/tests. |
| NCLF-022 | `work_claims_not_locks` | Work claims are coordination records by default, not exclusive locks. | implemented | ADR 0054, `LocalForgeWorkClaimRecord`, focused compatible-claim test, stale-claim transition test. | Rich coordination UI remains future work. |
| NCLF-023 | `explicit_exclusive_locks` | Exclusive locks exist only for high-risk refactors, unsafe path edits, or human freezes. | implemented | ADR 0054, `claw project claim --exclusive`, focused lock-conflict test. | Rich lock UI remains future work. |
| NCLF-024 | `recoverable_agent_changes` | Agent-authored changes require pre-change snapshots and recoverable checkpoints. | implemented | ADR 0054, metadata-only snapshot/checkpoint records, focused snapshot privacy test. | Actual Git commit creation remains opt-in future work. |
| NCLF-025 | `stale_claim_recovery` | Abandoned work must show intent, partial state, changes, and recovery/merge/abandon options. | implemented | ADR 0054, `evaluateLocalForgeStaleClaims`, `claw project forge-status --mark-stale`, `claw project recover`, focused local forge CLI tests. | Merge/conflict policy remains blocked separately. |
| NCLF-026 | `preflight_exclusions` | Large/generated/vendor/cache/private/secret-bearing files are blocked or excluded by preflight. | implemented | ADR 0054, `runLocalForgePreflight`, focused preflight/snapshot/review tests. | V1 large-file policy is `block_by_default`; future storage backend enablement remains separate. |
| NCLF-027 | `git_not_secret_store` | Git-backed history must not store plaintext secrets or host-private state. | implemented | ADR 0054, snapshot/review tests prove `.env` content is not persisted; project attach does not create `.git`. | Future Git-backed history must preserve the same guard. |
| NCLF-028 | `local_forge_not_provider_replacement` | Local forge is framework-owned review/recovery, not a GitHub/GitLab replacement. | documented | ADR 0054. | Provider interop remains separate. |
| NCLF-029 | `review_before_merge_policy` | Risky changes need explicit review before merge according to future policy. | blocked | ADR 0054, `LocalForgeMergePlanRecord`, focused detect-and-elevate test. | Metadata-only merge plans exist. Blocker: accepted review-before-merge policy is not implemented. Reentry: define policy gates and tests for when a plan may be merged. |
| NCLF-030 | `external_git_interop` | Existing GitHub/GitLab remotes interoperate without becoming local forge authority. | blocked | ADR 0054. | Needs external-provider design and fixtures. |
| NCLF-031 | `durable_node_identity` | Cluster membership starts from a durable cryptographic node identity generated or imported per device. | blocked | ADR 0053, `createNodeIdentity`. | Fingerprint binding is implemented; protected device-local key generation/import remains blocked pending signed-host or OS secure storage. |
| NCLF-032 | `mutable_node_locators` | Display names, hostnames, IPs, Tailscale addresses, Relay endpoints, and Iroh routes are mutable locators, not identity. | implemented | ADR 0053, `observedNodeLocatorSchema`, remote identity tests, redacted isolated physical core validation. | Real network locator refresh remains `EXTERNAL PENDING`. |
| NCLF-033 | `private_key_possession_handshake` | Remote handshakes must prove possession of the expected private key and separate identity verification from transport reachability. | implemented | ADR 0053, `RemoteTransportHandshakeReceipt`, focused tests, `claw nodes heartbeat --json`, redacted isolated physical core validation. | Physical transport proof remains `EXTERNAL PENDING`. |
| NCLF-034 | `signed_key_rotation` | A changed node key requires signed old-key rotation or explicit human re-pairing. | implemented | ADR 0053, `nodeKeyRotationReceiptSchema`, `createNodeKeyRotationReceipt`, focused remote contract tests. | Protected private-key storage and physical re-pairing proof remain separate blockers or `EXTERNAL PENDING`. |
| NCLF-035 | `discovery_not_authority` | Iroh, rendezvous, Relay, Tailscale, LAN, and other discovery mechanisms do not grant trust by themselves. | implemented | ADR 0053, locator/handshake authority fields, focused tests, redacted isolated physical core validation. | Physical discovery transport proof remains `EXTERNAL PENDING`. |
| NCLF-036 | `ip_not_authority` | Trust is granted to `nodeId` and public key fingerprint, never to an IP or network locator. | implemented | ADR 0053, `NodeTrustDecision.subjectNodeFingerprint`, mismatch tests, redacted isolated physical core validation. | Real multi-node locator evidence remains `EXTERNAL PENDING`. |
| NCLF-037 | `reconnect_identity_gate` | Reconnect after disconnect or locator refresh must verify node identity before remote work becomes available. | implemented | ADR 0053, `nodeReconnectReceiptSchema`, `createNodeReconnectReceipt`, focused remote contract tests. | Physical reconnect over live transports remains `EXTERNAL PENDING`; local contract is implemented. |
| NCLF-038 | `authority_handoff_audit_receipts` | Authority handoffs must produce inspectable audit receipts and remain pending until physical application is verified. | implemented | ADR 0053, `SyncAuthorityHandoffReceipt`, `createSyncAuthorityHandoffReceipt`, focused remote contract tests. | Coordinator/standby persistence and physical promotion remain blocked or `EXTERNAL PENDING` separately. |
| NCLF-039 | `nclf_surface_parity` | Node inventory, resource location, local forge inventory, and cluster control-plane inspection need SDK/API/MCP/Relay/host-bridge parity after local contracts exist. | implemented | `clawCapabilityCatalog`, `custom-app-sdk-contracts.ts`, focused capability catalog tests. | Live Relay/MCP execution remains bounded metadata projection; physical mutations remain `EXTERNAL PENDING`. |
