# @clawjs/domain-pack-dense-data

Optional Claw domain pack for deep dense-data commands.

The base `@clawjs/cli` package keeps only lightweight catalog and routing
metadata for niche domains. Install this pack only when those deep domain
commands are needed.

## Safety and legal

ClawJS is an assistive local-first framework. It may help with sensitive
records, summaries, searches, and non-final drafts, but it does not replace
regulated professionals, is not professional advice, and must not make final
medical, mental health, legal, financial, insurance, employment, education,
government, emergency, or physical-safety decisions. See
[SAFETY.md](https://github.com/clawic/clawjs/blob/main/SAFETY.md) and
